# Peloton Alternative

This app guides you through different style cycling workouts showing a cadence and resistance target range. Right now they are all 20 minutes long.

Built with Expo, React Native, and TypeScript.

📝 Follow along on my page [https://www.tianaruiz.com/projects/diy-fitness-app](#) where I'm documenting the build.

## Why

Peloton's hardware is optional — the subscription is really paying for class tracking, metrics, and a workout interface. This project explores building that experience from scratch, cutting the $600/year cost while learning React Native along the way.

## Tech Stack

- **Framework**: [Expo](https://expo.dev/) (React Native)
- **Language**: TypeScript
- **UI**: React 19 / React Native

## Getting Started

```bash
npm install
npm start
```

Then run on your platform of choice:

```bash
npm run ios      # iOS simulator
npm run android  # Android emulator
npm run web       # Web browser
```
